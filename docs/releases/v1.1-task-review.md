# ALE v1.1 task review

Task designs are frozen as of October 14, 2026. The table covers all **71 modified active tasks** in the [upgrade map](../../releases/v1.1/upgrade.json); retirements are listed separately. The map records the frozen source identity. Matching asset publication and release validation remain pending.

Local validation has covered **19 confirmed affected tasks** using Codex GPT-6 Astra high and Kimi K3 high. Candidate Linux/Windows images have been updated and boot-checked. The table records the scope and limits of the component checks; it does not certify complete agent validation or publication of the final assets. See the [release guide](v1.1.md) for matching code, data and environment requirements. Run evidence is retained separately, with bulk output collection disabled.

**Source** means local code changes; **Data candidate** means prepared replacement or exclusion data; **Retained** means the reviewed materials stay in place. Retained materials do not change a task's rerun classification. **Verified** identifies the specific checks that passed; **Reviewed** indicates a retained decision without a new execution check. These are contract, component and selected simulation checks, not a rerun of every task by an agent.
